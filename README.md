# Crypto Analyse

Cette application mobile permet d'obtenir des informations sur la crypto de son choix et de demander à un agent IA intégré une prédiction de son évolution sur les prochaines 24 heures.

## Installation front-end

1- Sur un téléphone, télécharger Expo
2- Sur un terminal, installer Expo : npx install expo
3- Lancer un npm install pour installer toutes les dépendances du projet
4- Lancer la commande npx expo start et vérifier que l'IP est bien trouvée par Expo sur mobile, puis essayer de la lancer
